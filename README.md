#PowerShell Automation Scripts

This repository contains PowerShell scripts created to automate common administrative and infrastructure tasks in my lab environment.

The goal of this project is to build practical scripting skills that support system administration, Active Directory management, and general IT automation. These scripts focus on reducing repetitive manual work, improving consistency, and reinforcing real-world infrastructure concepts.

---

## Project Purpose

PowerShell is one of the most important tools for Windows administration and infrastructure automation. This repository serves as a hands-on scripting portfolio to demonstrate practical experience with:

- task automation
- administrative scripting
- bulk operations
- system configuration
- infrastructure support workflows

The scripts in this repository are designed for learning, lab use, and continuous improvement.
